# Contributing

Use English for repository descriptions, documentation, branch names, commit messages, and pull requests. Preserve Brazilian Portuguese product labels unless a product-language change is requested.

Use your GitHub-provided `noreply` address for commit authorship. Review any new image before adding its exact path to the ignore-rule exceptions.

Work on a branch and open a pull request against `main`. Do not merge or rewrite published history without the owner's explicit request.

Keep changes scoped. Preserve firmware identity checks, release integrity checks, ownership checks, recovery guards, authorization gates, and accessibility behavior. Separate offline verification from physical-device evidence in every report.

Before committing, review the staged file list and diff. Never stage personal wallpapers, SSH keys, passwords, provider tokens, firmware dumps, screenshots with account data, raw TV backups, or old physical-session authorizations. Local-only does not mean disposable: unique backups and RED/GREEN evidence must be preserved.

For device-impacting changes, describe the trigger, resulting behavior, exact verification, and remaining limitations in the pull request. A passing host test is not evidence of a successful boot, usable video playback, or complete recovery on the TV.
